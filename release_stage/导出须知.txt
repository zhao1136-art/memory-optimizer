==========================================================
  内存优化工具 - 报告导出须知
==========================================================

导出的报告支持以下 5 种格式，不同格式需要用对应的软件才能打开。
请根据你机器上已安装的软件选择格式；如果下面标注的软件尚未安装，
可先安装相关软件，或改用 CSV / HTML / JSON 等无需安装的格式。

----------------------------------------------------------
1. HTML（网页文档）
   - 需要软件：无需安装，任何浏览器都能打开
   - 双击文件即可在浏览器中查看，带完整排版与样式
   - 适用性：最省事，无需额外安装

----------------------------------------------------------
2. CSV（逗号分隔表格）
   - 需要软件：无需专业软件
   - 可用：Excel / WPS 表格 / LibreOffice / 记事本 / 任意文本编辑器
   - 说明：纯文本，双击若被记事本打开属正常；想看到表格列效果，
     建议用 Excel 或 WPS 打开

----------------------------------------------------------
3. JSON（结构化数据）
   - 需要软件：无需安装
   - 用记事本、任意文本编辑器或浏览器打开即可查看
   - 适合程序二次处理

----------------------------------------------------------
4. PDF（便携式文档）
   - 需要软件：需安装任一 PDF 阅读器
   - 推荐：Adobe Acrobat Reader（免费）或以 PDF 阅读能力为主的浏览器
   - 中文环境建议：WPS Office 自带 PDF 阅读；Chrome / Edge 也可直接打开
   - 说明：若双击后提示"找不到打开程序"，请先安装上述任一阅读器

----------------------------------------------------------
5. XLS（电子表格）
   - 需要软件：需安装任一电子表格软件
   - 支持：Microsoft Excel / WPS 表格 / LibreOffice Calc
   - 重要提示：本文件实为"网页表格"格式，Excel / WPS 均可直接打开；
     首次打开若弹出"文件格式与扩展名不一致"的提示，选择"是/仍要打开"即可
     正常显示内容
   - 说明：没有安装上面任一软件则无法打开，建议用 CSV 代替

----------------------------------------------------------
推荐组合：
   - 只看报告 → HTML
   - 要用表格软件分析 → 安装 WPS 表格后导出 XLS / CSV
   - 要发给他人/打印 → 安装 PDF 阅读器后导出 PDF
   - 无需安装、最通用 → CSV / JSON / HTML
