# MemOptimizer（内存优化工具）介绍

MemOptimizer 是一款基于 **纯 C** 开发的 Windows 内存监控与优化工具。它通过持续采样进程内存指标，实时提供系统与进程的内存占用分析，并给出可执行的优化建议，帮助定位内存泄漏、清理不必要的内存占用，从而提升系统流畅度。

- **语言/实现**：纯 C（C11），原生 Win32 API，低开销、无第三方运行时依赖
- **运行环境**：Windows
- **交付形式**：单个可执行文件 `memtool.exe`，可选 Web 后台界面

---

## 主要功能

### 1. 实时内存监控
- 持续采样系统整体内存（物理内存、可用内存、提交限额、缓存/standby、句柄数、线程数）
- 覆盖进程维度：私有字节、工作集、峰值、CPU 占用、句柄数等

### 2. 内存占用热点分析
- 自动对进程按私有字节排名，定位占用最高的 Top 进程
- 结合运行时类型识别，辅助判断哪些程序最耗内存

### 3. 内存泄漏检测
- 针对长时间运行的进程做线性回归分析，识别内存持续增长的泄漏趋势
- 报告泄漏速率（KB/min）、拟合优度 R²、历时与严重度

### 4. 内存优化建议
- 基于监控数据自动生成优化建议（按严重度分级：高 / 中 / 低）
- 部分建议可直接一键执行

### 5. 一键优化
- 关闭长时间低 CPU 且高驻留内存的"僵尸"进程
- 回收高驻留进程的工作集
- 清理系统 standby 缓存
- 受保护进程一律跳过，避免误伤

### 6. 受保护进程名单
- 自定义需要保护、不被优化操作的进程名单
- 确保关键程序（IDE、服务器、浏览器等）不被误关闭或回收

### 7. 内存碎片分析
- 查看系统内存碎片状况，辅助判断是否需要进一步清理

### 8. 报告多格式导出
支持一键导出完整报告，数据与界面显示保持一致：

| 格式    | 说明                                   |
| ------- | -------------------------------------- |
| HTML    | 网页文档，任何浏览器打开               |
| PDF     | 含中文的便携文档，需 PDF 阅读器        |
| XLS     | 网页表格，Excel / WPS / LibreOffice 打开 |
| CSV     | 逗号分隔表格，通用性强                 |
| JSON    | 结构化数据，便于程序处理               |

> 各格式所需软件详见《导出须知》。

## 使用方法

### 命令行启动 Web 后台

```bat
memtool.exe --serve
```

启动后用浏览器访问内置后台地址（默认 `http://127.0.0.1:8080`），即可实时查看监控数据并执行优化。

### 命令行导出报告

```bat
rem 直接生成 HTML 报告
memtool.exe --report html

rem 导出 JSON / XLS / PDF / CSV
memtool.exe --report json
memtool.exe --report xls
memtool.exe --report pdf
memtool.exe --report csv
```

### 一键优化

```bat
memtool.exe --oneclick
```

## 配置文件

`memtool.conf` 可调整以下参数：

- **server**：监听地址、端口、远程访问开关、API 鉴权令牌
- **sampler**：采样间隔、采样窗口大小、自动关注的进程数
- **storage**：历史数据留存开关、保存目录、保留时长

---

## 目标用户与适用场景

- **普通用户**：系统卡顿、内存占用过高时，一键识别并清理高占用/僵尸进程
- **开发与运维**：定位进程内存泄漏、分析长期无人值守进程的内存增长趋势
- **性能排查**：快速生成可视化报告并导出，用于记录与分享
